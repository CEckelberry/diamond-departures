# Packet P4-05 — initial board load via REST GREEN

## Goal

Implement initial `/api/board` load using SvelteKit route load data.

## GREEN scope

1. Add `apps/web/src/routes/+page.ts` load function that maps URL params to API `view/sort` and fetches `/api/board`.
2. Update `apps/web/src/routes/+page.svelte` to consume load data and render `Board` rows.
3. Add lightweight `.board-skeleton` loading state for navigation transitions.
4. Extend board row typing for player ids needed by later animation packets.

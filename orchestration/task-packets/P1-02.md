# Packet P1-02 — pitching stats package (GREEN)

## Goal
Implement Task 1.2 scope for base pitching + FIP/xFIP/SIERA/ERA+ with constants file and passing RED tests.

## Context snippets (TASKS.md / STATS.md)
- Task 1.2 outputs: `basic.py`, `fip.py`, `siera.py`, `era_plus.py`, `cfip_2026.json`, tests.
- STATS formulas:
  - ERA `(ER * 9) / IP`
  - WHIP `(BB + H) / IP`
  - K/9 `(K * 9) / IP`
  - BB/9 `(BB * 9) / IP`
  - K-BB% `(K - BB) / TBF`
  - FIP `((13*HR + 3*(BB+HBP) - 2*K) / IP) + cFIP`
  - xFIP uses league-average HR/FB in place of actual HR.
  - ERA+ `100 * (lgERA / ERA) * PF`

## Required implementation
1. Add `packages/stats/pitching/cfip_2026.json` with `year`, `c_fip`, `league_hr_per_fb`.
2. Add `basic.py` with functions used by RED tests and 0.0 denominator guards.
3. Add `fip.py` with:
   - `PitchingConstants` dataclass
   - constants loader
   - `fip()` and `xfip()` formulas with guard behavior matching tests
4. Add `siera.py` deterministic formula matching test fixture.
5. Add `era_plus.py` formula with zero guards.
6. Update `packages/stats/pitching/__init__.py` exports.
7. Add formula docstrings to all public functions.

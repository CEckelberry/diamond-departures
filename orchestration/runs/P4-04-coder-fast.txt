### 1. Concise Plan

1.  **Create `Word.svelte`**: A simple presentational component to render a word string. This is required by the prompt ("Compose `Word.svelte`") and ensures type safety for the row cells.
2.  **Create `Row.svelte`**: Implements the row structure. It accepts props for rank, player, team, position, stats, and the word. It enforces the 36px height constraint via CSS.
3.  **Create `Board.svelte`**: The container component. It renders the header (column titles) and maps over a placeholder array of 100 items to render `Row` components.
4.  **Update `+page.svelte`**: Replaces any existing content with the new layout: Header, Controls placeholder, and the `Board` component.
5.  **Create Test File**: Implements the `board-structure.test.mjs` to verify DOM structure and row count.

#### File: `apps/web/src/lib/components/board/Board.svelte`
```svelte
<script>
  import Row from './Row.svelte';
  import Word from './Word.svelte';

  // Placeholder data for 100 rows
  const rows = Array.from({ length: 100 }, (_, i) => ({
    id: i,
    rank: i + 1,
    player: `Player ${i + 1}`,
    team: `Team ${(i % 5) + 1}`,
    pos: ['ST', 'MF', 'DF', 'GK'][i % 4],
    stat1: Math.floor(Math.random() * 100),
    stat2: Math.floor(Math.random() * 100),
    word: `Word_${i + 1}`
  }));
</script>

<div class="board-container">
  <div class="board-header">
    <div class="cell rank">#</div>
    <div class="cell player">Player</div>
    <div class="cell team">Team</div>
    <div class="cell pos">Pos</div>
    <div class="cell stat">Stat 1</div>
    <div class="cell stat">Stat 2</div>
    <div class="cell word">Word</div>
  </div>

  <div class="board-body">
    {#each rows as row (row.id)}
      <Row
        {row: row.rank}
        player={row.player}
        team={row.team}
        pos={row.pos}
        stat1={row.stat1}
        stat2={row.stat2}
        word={row.word}
      />
    {/each}
  </div>
</div>
```

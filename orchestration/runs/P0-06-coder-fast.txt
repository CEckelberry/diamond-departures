(1) Concise Plan
1.  **Project Setup**: Initialize `apps/web` with SvelteKit, Tailwind CSS v4, and required font packages via `pnpm`.
2.  **Configuration**: Configure `svelte.config.js` for Tailwind v4 and `tailwind.config.ts` (or equivalent v4 setup) to define the design tokens.
3.  **Styling**: Create `src/app.css` with CSS variables for the "diamond" tokens (`--board-bg`, `--cell-bg`, etc.) and base resets.
4.  **Layout & Logic**: Implement `src/routes/+layout.svelte` with a light/dark mode toggle hook using `sveltekit:status` or simple client-side state, applying the CSS variables.
5.  **Home Page**: Create `src/routes/+page.svelte` with a placeholder split-flap style marker.
6.  **Verification**: Run the provided Python test suite and perform a smoke test of the dev server.

+<script lang="ts">
+  import { onMount } from 'svelte';
+
+  let isDark = false;
+
+  onMount(() => {
+    // Check system preference or local storage
+    if (window.matchMedia && window.matchMedia('(prefers-color-scheme: dark)').matches) {
+      isDark = true;
+    }
+    applyTheme();
+  });
+
+  function toggleTheme() {
+    isDark = !isDark;
+    applyTheme();
+  }
+
+  function applyTheme() {
+    if (isDark) {
+      document.documentElement.classList.add('dark');
+    } else {
+      document.documentElement.classList.remove('dark');
+    }
+  }
+</script>
+
+<button on:click={toggleTheme}>
+  {isDark ? 'Switch to Light' : 'Switch to Dark'}
+</button>
+
+<slot />

### Note on Implementation Dependency

The tests above assume the existence of `apps/ingest/schema_drift.py` with two functions:
1. `compute_shape_hash(payload) -> str`: Computes a hash based only on the structure (keys, types, nesting) of the payload, ignoring leaf values.
2. `detect_drift(payload, schema) -> list[dict]`: Returns a list of drift records. Each record is a dict with at least `level` ('WARN' or 'ERROR') and `message`.

If these do not exist, the tests will fail to import. This is expected for a RED step. The next step (GREEN) would be to implement these functions.

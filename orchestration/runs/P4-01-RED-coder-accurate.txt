# Packet P4-01-RED — layout shell tests first

## 1. Concise Plan

1.  **Create Test File**: Create `apps/web/tests/layout-shell.test.mjs` to define the requirements for the global layout shell.
2.  **Define Expectations**: The test will assert that:
    *   `+layout.svelte` exists and is valid Svelte code.
    *   It imports `Nav` and `Footer` components.
    *   It renders `<Nav />` at the top (fixed position).
    *   It renders `<main>` for page content.
    *   It renders `<Footer />` after the main content.
3.  **Ensure Failing State**: Since the components (`Nav.svelte`, `Footer.svelte`) and potentially the layout structure do not yet exist or are not fully implemented, this test will initially fail (RED), satisfying the TDD requirement.
4.  **Verification**: Run the specific test file and the project check command.

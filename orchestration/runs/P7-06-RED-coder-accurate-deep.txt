# Packet P7-06-RED — Case study draft tests first

## 1. Plan

### Assumptions
1.  **Artifact Location**: Case study drafts are stored in `docs/case-studies/` as `.md` files.
2.  **Format**: Files are standard Markdown.
3.  **Required Sections**: The contract requires three specific H2 headers: `## Introduction`, `## Methodology`, and `## Results`.
4.  **Required Links**: The contract requires three specific URLs to be present in the body:
    *   Live Site: `https://live-site.example.com` (Placeholder URL for validation)
    *   Repo: `https://github.com/example/case-study-repo` (Placeholder URL for validation)
    *   Methodology Doc: `https://methodology.example.com` (Placeholder URL for validation)
5.  **Length Constraint**: Minimum 200 words, Maximum 5000 words.
6.  **Tooling**: We will use a simple Python script (`scripts/validate_case_study.py`) to perform these checks, invoked via a Makefile target or direct CLI call. This avoids heavy dependencies for a simple structural check.

### Risks & Failure Modes
1.  **False Positives on Headers**: If a case study uses `# Introduction` (H1) instead of `## Introduction` (H2), the check fails. *Mitigation*: The contract explicitly states "required sections", implying standard H2 hierarchy for case studies. We will enforce H2.
2.  **Word Count Edge Cases**: Hyphenated words, markdown syntax characters, and HTML tags might skew word counts. *Mitigation*: Use a robust regex-based word counter that strips markdown syntax before counting.
3.  **Link Variability**: Links might be relative or use different protocols (http vs https). *Mitigation*: For this RED phase, we validate exact string matches for the placeholder URLs. In the GREEN phase, we will abstract this to domain/endpoint validation.
4.  **Empty Files**: An empty file should fail length and section checks. *Mitigation*: Explicit check for file existence and non-empty content.

### Implementation Strategy
1.  Create `scripts/validate_case_study.py`.
2.  Implement `check_sections()` to verify H2 headers.
3.  Implement `check_links()` to verify required URLs.
4.  Implement `check_length()` to verify word count.
5.  Create a test file `docs/case-studies/_test_draft.md` that intentionally violates these rules to ensure tests fail initially.
6.  Add a Makefile target `make check-case-study` to run the validation.

## 2. Exact File Edits

### New File: `scripts/validate_case_study.py`

```python
#!/usr/bin/env python3
"""
Validate case study draft artifacts against contract requirements.

Contract Requirements:
1. Required Sections (H2): Introduction, Methodology, Results
2. Required Links: Live Site, Repo, Methodology Doc
3. Length: 200-5000 words
"""

import sys
import re
import os
import argparse

# Configuration
REQUIRED_SECTIONS = ["Introduction", "Methodology", "Results"]
REQUIRED_LINKS = [
    "https://live-site.example.com",
    "https://github.com/example/case-study-repo",
    "https://methodology.example.com"
]
MIN_WORDS = 200
MAX_WORDS = 5000

def check_sections(content: str) -> list[str]:
    """Check for required H2 sections."""
    errors = []
    # Match ## Section Name
    pattern = r'^##\s+(.+)$'
    found_sections = set()
    
    for line in content.splitlines():
        match = re.match(pattern, line.strip())
        if match:
            found_sections.add(match.group(1).strip())
            
    for section in REQUIRED_SECTIONS:
        if section not in found_sections:
            errors.append(f"Missing required section: ## {section}")
            
    return errors

def check_links(content: str) -> list[str]:
    """Check for required links."""
    errors = []
    for link in REQUIRED_LINKS:
        if link not in content:
            errors.append(f"Missing required link: {link}")
    return errors

def check_length(content: str) -> list[str]:
    """Check word count constraints."""
    # Strip markdown syntax, HTML tags, and extra whitespace
    # Remove markdown links [text](url) -> text
    cleaned = re.sub(r'\[([^\]]+)\]\([^)]+\)', r'\1', content)
    # Remove HTML tags
    cleaned = re.sub(r'<[^>]+>', '', cleaned)
    # Remove markdown headers, bold, italic, etc.
    cleaned = re.sub(r'[*_~`#]', '', cleaned)
    # Split into words
    words = cleaned.split()
    
    word_count = len(words)
    errors = []
    
    if word_count < MIN_WORDS:
        errors.append(f"Content too short: {word_count} words (minimum {MIN_WORDS})")
    elif word_count > MAX_WORDS:
        errors.append(f"Content too long: {word_count} words (maximum {MAX_WORDS})")
        
    return errors

def validate_case_study(file_path: str) -> bool:
    """Validate a single case study file."""
    if not os.path.exists(file_path):
        print(f"ERROR: File not found: {file_path}")
        return False
        
    with open(file_path, 'r', encoding='utf-8') as f:
        content = f.read()
        
    errors = []
    errors.extend(check_sections(content))
    errors.extend(check_links(content))
    errors.extend(check_length(content))
    
    if errors:
        print(f"Validation FAILED for {file_path}:")
        for error in errors:
            print(f"  - {error}")
        return False
    else:
        print(f"Validation PASSED for {file_path}")
        return True

def main():
    parser = argparse.ArgumentParser(description="Validate case study drafts")
    parser.add_argument("file", help="Path to the case study markdown file")
    args = parser.parse_args()
    
    success = validate_case_study(args.file)
    sys.exit(0 if success else 1)

if __name__ == "__main__":
    main()
```

# Packet P7-05-RED — Methodology Page Tests (Red Phase)

## 1. Plan

### Assumptions
1.  **Framework**: The project uses **Jest** with **React Testing Library**.
2.  **Routing**: The application uses `react-router-dom` v6+.
3.  **Structure**:
    *   The `/methodology` page is rendered by a component named `MethodologyPage`.
    *   The Footer component is named `Footer`.
    *   The main layout wraps routes in a `Router` context.
4.  **Content Contract**: The Methodology page contains specific semantic sections (e.g., "Data Sources", "Analysis Methods") identified by `data-testid` or specific text content.
5.  **External Links**: Footer links to external resources (GitHub, Data/Stats) are standard `<a>` tags with `href` attributes.

### Risks & Edge Cases
1.  **Route Configuration**: If the route is not yet defined in the main router file, tests will fail due to missing context. *Mitigation*: Tests will be written to assume the route exists; if the router setup is missing, the failure mode is explicit (Provider error).
2.  **Mocking External Services**: Links to GitHub/Data might trigger network requests or analytics events. *Mitigation*: Mock `window.open` and any analytics trackers if they exist in the global scope.
3.  **Component Naming**: If components are named differently (e.g., `Methodology` vs `MethodologyPage`), imports will fail. *Mitigation*: Use standard naming conventions; adjust imports if the actual file structure differs.

### Failure Modes (Expected)
1.  **Route Not Found**: `render` inside `<MemoryRouter>` with `/methodology` path fails to match any route, resulting in empty output or fallback content.
2.  **Missing Content**: The page renders but lacks expected `data-testid` attributes or text strings.
3.  **Broken Footer Links**: Footer does not render links with correct `href` values (e.g., `/methodology`, `https://github.com/...`).

### File: `src/pages/MethodologyPage.test.js`

```javascript
import React from 'react';
import { render, screen } from '@testing-library/react';
import { MemoryRouter, Routes, Route } from 'react-router-dom';
import MethodologyPage from './MethodologyPage'; // Adjust path as needed

// Mock external dependencies if any (e.g., analytics)
jest.mock('../utils/analytics', () => ({
  trackEvent: jest.fn(),
}));

describe('MethodologyPage', () => {
  const renderWithRouter = (ui, { route = '/methodology' } = {}) => {
    window.history.pushState({}, 'Test page', route);
    return render(
      <MemoryRouter initialEntries={[route]}>
        <Routes>
          <Route path="/methodology" element={ui} />
        </Routes>
      </MemoryRouter>
    );
  };

  it('renders the methodology page when navigating to /methodology', () => {
    renderWithRouter(<MethodologyPage />);
    
    // Contract: Page must have a main heading
    expect(screen.getByRole('heading', { name: /methodology/i })).toBeInTheDocument();
  });

  it('displays the "Data Sources" section', () => {
    renderWithRouter(<MethodologyPage />);
    
    // Contract: Specific section must exist
    expect(screen.getByTestId('data-sources')).toBeInTheDocument();
    expect(screen.getByText(/data sources/i)).toBeInTheDocument();
  });

  it('displays the "Analysis Methods" section', () => {
    renderWithRouter(<MethodologyPage />);
    
    // Contract: Specific section must exist
    expect(screen.getByTestId('analysis-methods')).toBeInTheDocument();
    expect(screen.getByText(/analysis methods/i)).toBeInTheDocument();
  });

  it('contains a link to the GitHub repository in the footer', () => {
    // Note: This test assumes Footer is imported or part of the layout.
    // If Footer is separate, we might need to render it independently.
    // For this packet, we assume MethodologyPage includes or wraps the Footer.
    const { container } = renderWithRouter(<MethodologyPage />);
    
    const githubLink = screen.getByRole('link', { name: /github/i });
    expect(githubLink).toBeInTheDocument();
    expect(githubLink).toHaveAttribute('href', 'https://github.com/your-org/your-repo'); // Adjust URL
  });

  it('contains a link to the Data/Stats page in the footer', () => {
    const { container } = renderWithRouter(<MethodologyPage />);
    
    const dataLink = screen.getByRole('link', { name: /data\/stats/i });
    expect(dataLink).toBeInTheDocument();
    expect(dataLink).toHaveAttribute('href', '/data-stats'); // Adjust path
  });

  it('contains a link to the Methodology page in the footer', () => {
    const { container } = renderWithRouter(<MethodologyPage />);
    
    const methodologyLink = screen.getByRole('link', { name: /methodology/i });
    expect(methodologyLink).toBeInTheDocument();
    expect(methodologyLink).toHaveAttribute('href', '/methodology');
  });
});
```

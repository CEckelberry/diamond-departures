(1) Concise Plan
The goal is to create a test suite that asserts the existence and basic behavior of the player detail panel components. Since the implementation (`$lib/components/player/Panel.svelte`, `Row.svelte`, `Board.svelte`) does not yet exist, the tests will fail on import or runtime errors, satisfying the "keep tests failing" requirement.

1.  Create `apps/web/tests/player-panel-shell.test.mjs`.
2.  Import `Panel`, `Row`, and `Board` from their respective paths in `$lib/components/player/`.
3.  Assert that `Panel` renders a wrapper with the `selectedPlayer` prop passed through.
4.  Assert that `Row` accepts a `playerId` and emits a click event.
5.  Assert that `Board` renders rows and forwards selection events.
6.  Assert that `Panel` contains specific DOM markers for empty/loading/error states (even if currently unimplemented, the structure should be expected).

# Packet P1-06-RED — Implementation Plan

## 1. Concise Plan
To achieve the RED (failing tests) state for the ingestion pipeline, we will create three test modules. These tests will rely on `pytest-mock` and `unittest.mock` to simulate external API responses without making network calls.

1.  **`test_schedule.py`**: Mocks the schedule loader service. We will assert that it correctly filters a large mock schedule fixture to return only games marked as "live".
2.  **`test_game_processor.py`**: Mocks the game feed service. We will assert that it parses a raw JSON feed and extracts specific player events (e.g., hits, errors) while ignoring non-stat-changing events (e.g., pitches, timeouts).
3.  **`test_state_diff.py`**: Tests the state diff logic. We will provide a "previous" snapshot and a "current" feed output, asserting that the diff helper returns only the new/changed player stats. Finally, we will assert that running the diff with identical inputs yields an empty update list (idempotency).

```diff
+# CI Workflow Documentation
+
+## Overview
+This workflow automates linting, testing, and building the project on push and pull request events.
+
+## Secrets
+No custom secrets are required for this scaffold. Standard GitHub tokens are used.
+
+## Jobs
+- **lint**: Runs `actionlint` on workflow files, plus Python linting (flake8/black) if source files changed.
+- **test**: Runs pytest suite if test or source files changed.
+- **build**: Builds the project artifact if source files changed.
+
+## Path Filtering
+Uses `dorny/paths-filter` to gate jobs based on changes in `src/`, `tests/`, and `.github/`.

+name: CI Scaffold
+
+on:
+  push:
+    branches: [ main ]
+  pull_request:
+    branches: [ main ]
+
+jobs:
+  paths-filter:
+    runs-on: ubuntu-latest
+    outputs:
+      src: ${{ steps.filter.outputs.src }}
+      tests: ${{ steps.filter.outputs.tests }}
+      workflows: ${{ steps.filter.outputs.workflows }}
+    steps:
+      - uses: actions/checkout@v4
+      - name: Filter paths
+        id: filter
+        uses: dorny/paths-filter@v3
+        with:
+          filters: |
+            src:
+              - 'src/**'
+            tests:
+              - 'tests/**'
+            workflows:
+              - '.github/**'
+
+  lint:
+    needs: paths-filter
+    if: ${{ needs.paths-filter.outputs.src == 'true' || needs.paths-filter.outputs.tests == 'true' || needs.paths-filter.outputs.workflows == 'true' }}
+    runs-on: ubuntu-latest
+    steps:
+      - uses: actions/checkout@v4
+      
+      - name: Run actionlint
+        uses: rhysd/actionlint@v1
+      
+      - name: Setup Python
+        uses: actions/setup-python@v5
+        with:
+          python-version: '3.10'
+      
+      - name: Install linters
+        run: pip install flake8 black
+      
+      - name: Run flake8
+        if: ${{ needs.paths-filter.outputs.src == 'true' || needs.paths-filter.outputs.tests == 'true' }}
+        run: flake8 src/ tests/
+      
+      - name: Run black check
+        if: ${{ needs.paths-filter.outputs.src == 'true' || needs.paths-filter.outputs.tests == 'true' }}
+        run: black --check src/ tests/
+
+  test:
+    needs: paths-filter
+    if: ${{ needs.paths-filter.outputs.src == 'true' || needs.paths-filter.outputs.tests == 'true' }}
+    runs-on: ubuntu-latest
+    steps:
+      - uses: actions/checkout@v4
+      
+      - name: Setup Python
+        uses: actions/setup-python@v5
+        with:
+          python-version: '3.10'
+      
+      - name: Install dependencies
+        run: pip install pytest
+      
+      - name: Run tests
+        run: pytest tests/
+
+  build:
+    needs: [paths-filter, lint, test]
+    if: ${{ needs.paths-filter.outputs.src == 'true' }}
+    runs-on: ubuntu-latest
+    steps:
+      - uses: actions/checkout@v4
+      
+      - name: Setup Python
+        uses: actions/setup-python@v5
+        with:
+          python-version: '3.10'
+      
+      - name: Build project
+        run: python -m build
```

# Packet P7-03-RED — Mobile experience tests first

## 1. Plan

### Assumptions
1.  **Framework**: React + TypeScript (standard modern stack).
2.  **Testing Library**: `@testing-library/react` and `@testing-library/jest-dom`.
3.  **Styling**: CSS Modules or standard CSS classes (e.g., `.board`, `.row`, `.card`, `.btn-primary`).
4.  **Viewport**: Tests simulate a 375px width (iPhone SE/standard mobile).
5.  **Existing Structure**: A `Board` component exists which renders `Row`s, which render `Card`s. Primary controls are buttons or interactive divs within these components.

### Risks & Edge Cases
1.  **Layout Engine Dependency**: If the app uses a CSS framework (Tailwind/Bootstrap), we must ensure the test environment respects media queries. *Mitigation*: We will use `resize-observer-polyfill` or manual style injection to force the viewport width in the JSDOM environment, as JSDOM does not natively support media queries.
2.  **Tap Target Measurement**: CSS `min-height`/`min-width` vs. actual rendered box model. *Mitigation*: We will assert against the computed style of the element's bounding box or specific CSS properties known to define tap targets.
3.  **Horizontal Scroll**: This is often caused by fixed-width elements overflowing a flex container. *Mitigation*: We will check `scrollWidth > clientWidth` on the main container.

### Implementation Strategy
1.  Create `MobileLayout.test.tsx`.
2.  Mock the `Board` component hierarchy.
3.  **Test 1: Card Layout**: Assert that at 375px, cards stack vertically (flex-direction: column) rather than horizontally.
4.  **Test 2: Tap Targets**: Assert that primary interactive elements have a minimum dimension of 44px (accessibility standard).
5.  **Test 3: No Horizontal Scroll**: Assert the main container does not exceed the viewport width.

+import React from 'react';
+import { render, screen } from '@testing-library/react';
+import { Board } from '../Board';
+import '@testing-library/jest-dom';
+
+// Mock ResizeObserver to prevent errors in JSDOM
+class ResizeObserverMock {
+  observe() {}
+  unobserve() {}
+  disconnect() {}
+}
+(window as any).ResizeObserver = ResizeObserverMock;
+
+describe('P7-03: Mobile Experience (375px)', () => {
+  const originalInnerWidth = window.innerWidth;
+  const originalInnerHeight = window.innerHeight;
+
+  beforeEach(() => {
+    // Simulate mobile viewport
+    Object.defineProperty(window, 'innerWidth', { writable: true, configurable: true, value: 375 });
+    Object.defineProperty(window, 'innerHeight', { writable: true, configurable: true, value: 812 });
+    
+    // Force JSDOM to re-evaluate media queries if using CSS-in-JS or standard CSS
+    // Note: In a real setup, you might need resize-observer-polyfill or 
+    // manual style injection for @media queries to trigger.
+    window.dispatchEvent(new Event('resize'));
+  });
+
+  afterEach(() => {
+    Object.defineProperty(window, 'innerWidth', { value: originalInnerWidth });
+    Object.defineProperty(window, 'innerHeight', { value: originalInnerHeight });
+  });
+
+  test('assertion 1: Board rows stack vertically on mobile (no horizontal scroll)', () => {
+    // Arrange
+    const mockRows = [
+      { id: 'r1', cards: [{ id: 'c1', title: 'Card 1' }, { id: 'c2', title: 'Card 2' }] },
+      { id: 'r2', cards: [{ id: 'c3', title: 'Card 3' }] }
+    ];
+
+    // Act
+    render(<Board rows={mockRows} />);
+
+    // Assert: Check main container width vs scroll width
+    const mainContainer = document.querySelector('.board-container') || document.body;
+    
+    // If the layout is broken (horizontal scroll), scrollWidth > clientWidth
+    expect(mainContainer.scrollWidth).toBeLessThanOrEqual(mainContainer.clientWidth + 1); // Allow 1px float error
+
+    // Assert: Cards should be block-level or flex-column, not inline/flex-row overflowing
+    const cards = screen.getAllByRole('article'); // Assuming cards are articles
+    cards.forEach(card => {
+      const style = window.getComputedStyle(card);
+      // Ensure card doesn't force horizontal overflow
+      expect(style.overflow).not.toBe('hidden'); // Or check specific layout properties
+    });
+  });
+
+  test('assertion 2: Primary controls meet 44px tap target minimum', () => {
+    // Arrange
+    const mockRows = [
+      { 
+        id: 'r1', 
+        cards: [{ id: 'c1', title: 'Card 1' }],
+        actions: [{ id: 'a1', label: 'Edit' }, { id: 'a2', label: 'Delete' }]
+      }
+    ];
+
+    // Act
+    render(<Board rows={mockRows} />);
+
+    // Assert: Find primary buttons/interactive elements
+    const buttons = screen.getAllByRole('button');
+    
+    buttons.forEach(btn => {
+      const rect = btn.getBoundingClientRect();
+      const computedStyle = window.getComputedStyle(btn);
+      
+      // Check height and width
+      expect(rect.height).toBeGreaterThanOrEqual(44);
+      expect(rect.width).toBeGreaterThanOrEqual(44);
+      
+      // Alternative: Check CSS min-height/min-width if JS measurement is unreliable in test env
+      const minHeight = parseFloat(computedStyle.minHeight) || parseFloat(computedStyle.height);
+      const minWidth = parseFloat(computedStyle.minWidth) || parseFloat(computedStyle.width);
+      
+      expect(minHeight).toBeGreaterThanOrEqual(44);
+      expect(minWidth).toBeGreaterThanOrEqual(44);
+    });
+  });
+
+  test('assertion 3: No horizontal scroll contract in route/layout CSS', () => {
+    // This test verifies the DOM structure doesn't inherently break layout
+    // even if CSS isn't fully loaded in JSDOM, we check for overflow properties
+    const mainContainer = document.querySelector('.board-container') || document.body;
+    
+    const style = window.getComputedStyle(mainContainer);
+    
+    // Assert: Overflow-x should not be 'auto' or 'scroll' unless necessary, 
+    // but ideally 'hidden' or 'visible' with proper sizing.
+    // For this RED test, we assert that the element itself isn't wider than 375px.
+    expect(mainContainer.scrollWidth).toBeLessThanOrEqual(375 + 1);
+  });
+});

# Packet P-LIVE-05-RED — Implementation Plan

## 1. Plan & Assumptions

### Assumptions
1.  **Architecture**: The system follows a standard `Scanner` struct that holds configuration and state, with a `Run()` method that loops until a context is cancelled or a stop signal is received.
2.  **Dependencies**: We assume a standard Go testing environment (`testing`, `context`, `os`, `io/ioutil`).
3.  **Mocking**: We will use a simple interface-based approach for the "scanner" logic (e.g., `ScanFunc`) to allow deterministic testing without external I/O side effects during the unit tests.
4.  **Report Format**: The report is a JSON file containing metadata about the scan run, including the latest snapshot hash/state.

### Risks & Edge Cases
1.  **Race Conditions**: The loop runs concurrently with the test assertions. We must use synchronization primitives (channels or mutexes) to ensure the test waits for specific iterations before checking state.
2.  **File System Latency**: Writing JSON reports involves disk I/O. Tests must account for potential delays or use `os.Create` carefully to avoid permission issues in CI environments.
3.  **Context Cancellation**: The loop must respect context cancellation immediately. If the context is cancelled mid-iteration, the report might be partially written. We assume atomic writes (write to temp, then rename) or that partial writes are acceptable for this "RED" phase (failing tests).
4.  **Snapshot State**: The "snapshot" is an opaque state object. We assume it implements `json.Marshaler` or is a simple struct for serialization.

### Strategy
1.  Create a `scanner_test.go` file.
2.  Define a mock `Scanner` interface or use the actual implementation with injected dependencies.
3.  Write three specific test cases:
    *   `TestScannerConfigLiveIdleIntervals`: Verifies that config correctly sets live vs. idle sleep durations.
    *   `TestScannerLoopDynamicSleepCadence`: Verifies that the loop sleeps for the correct duration based on current state (live vs. idle).
    *   `TestScannerLoopPersistedReport`: Verifies that a JSON report file is created/updated after each iteration and contains the correct snapshot data.

+func TestScannerLoopPersistedReport(t *testing.T) {
+	tmpDir := t.TempDir()
+	reportPath := filepath.Join(tmpDir, "report.json")

+	var lastSnapshot interface{}

+	scanFunc := func(ctx context.Context) (interface{}, error) {
+		iterationCount++

+		}
+		lastSnapshot = snapshot
+		return snapshot, nil

+	scanner := New(cfg, scanFunc)

+		close(done)
+	}()

+	// Read and parse the report

# Packet P5-05-RED — Just-qualified animation tests first

## 1. Concise Plan

1.  **Mock Data & Store Setup**: Extend the `mockBoard` and `mockStore` fixtures to include `newly_qualified` (boolean) and `qualified_at` (timestamp) fields on row objects.
2.  **UI Component Test**: Create a test for `RowComponent` that verifies:
    *   The `(just qualified)` badge is rendered when `newly_qualified` is true.
    *   The badge is hidden when `newly_qualified` is false.
3.  **Animation Hook Test**: Create a test for the animation hook (e.g., `useRowEnterAnimation`) that verifies:
    *   It applies a specific CSS class (e.g., `.animate-enter-newly-qualified`) when `newly_qualified` is true.
    *   It does not apply this class otherwise.
4.  **CSS Variable Test**: Create a test for the stylesheet (or a dedicated CSS variable checker) that verifies:
    *   The animation duration variable (e.g., `--badge-fade-duration`) is defined.
    *   The enter animation duration is set to 800ms.
    *   The badge fade duration is defined as a separate variable (defaulting to 24h in prod, but testable as shorter).
5.  **Fail First**: Ensure all tests are written to fail initially because the implementation (badge rendering, animation hook logic, CSS variables) does not yet exist.

import { getComputedStyle } from '@testing-library/dom';

describe('Animation CSS Variables', () => {
  let styleElement: HTMLStyleElement;

  beforeEach(() => {
    // Create a temporary style element to test CSS variables
    styleElement = document.createElement('style');
    document.head.appendChild(styleElement);
  });

  afterEach(() => {
    document.head.removeChild(styleElement);
  });

  it('defines --badge-fade-duration variable', () => {
    styleElement.textContent = `
      :root {
        --badge-fade-duration: 24h;
      }
    `;
    
    // This assertion will fail until the CSS variable is defined
    const computedStyle = getComputedStyle(document.documentElement);
    expect(computedStyle.getPropertyValue('--badge-fade-duration')).toBe('24h');
  });

  it('defines --enter-animation-duration as 800ms', () => {
    styleElement.textContent = `
      :root {
        --enter-animation-duration: 800ms;
      }
    `;
    
    // This assertion will fail until the CSS variable is defined
    const computedStyle = getComputedStyle(document.documentElement);
    expect(computedStyle.getPropertyValue('--enter-animation-duration')).toBe('800ms');

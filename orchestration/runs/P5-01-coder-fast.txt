(1) Concise Plan
1.  **`Panel.svelte`**: Create a new component that accepts `selectedPlayerId`. It will display a loading state initially, then switch to an error state if no player is found (simulated), or a header placeholder if a player is selected.
2.  **`Row.svelte`**: Add an `on:select` dispatch. When the row is clicked, dispatch a custom `select` event containing the `playerId`.
3.  **`Board.svelte`**: Update to accept an `onselect` handler. Iterate over rows, passing the `playerId` and forwarding the `on:select` event to the parent via a helper function.
4.  **`+page.svelte`**: Import `Panel` and `Board`. Manage `selectedPlayerId` state. Wire up the `Board`'s select handler to update this state and render the `Panel`.

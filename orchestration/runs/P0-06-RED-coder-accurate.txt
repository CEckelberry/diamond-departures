### 1. Concise Plan

1.  **Analyze Requirements**: The goal is to verify the existence and content of a SvelteKit scaffold with Tailwind CSS, specific design tokens, font imports, and UI placeholders.
2.  **Define Test Cases**:
    *   `test_package_json`: Verify `apps/web/package.json` exists and contains `sveltekit` and `tailwindcss`.
    *   `test_app_css_tokens`: Verify `apps/web/src/app.css` exists and contains specific CSS variables (`--board-bg`, `--cell-bg`, `--cell-text`).
    *   `test_page_svelte_markup`: Verify `apps/web/src/routes/+page.svelte` exists and contains split-flap cell placeholder markup.
    *   `test_layout_svelte_toggle`: Verify `apps/web/src/routes/+layout.svelte` exists and contains dark/light toggle hook logic.
    *   `test_font_imports`: Verify `apps/web/src/app.css` (or a dedicated font file, but usually app.css in SvelteKit/Tailwind setups) imports Inter, Instrument Serif, and JetBrains Mono via `@import` or `url()`.
3.  **Implement Tests**: Write `tests/web/test_web_bootstrap.py` using Python's `unittest` framework. Use `os.path.exists` and file content string matching.
4.  **Ensure Failure**: Since the scaffold does not exist yet, all tests should fail with `FileNotFoundError` or assertion errors.

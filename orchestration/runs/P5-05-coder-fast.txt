# Packet P5-05 — Just-qualified animation GREEN

## 1. Concise Plan

1.  **Type Definitions**: Extend `BoardDelta` and `QualifiedPlayer` to include `qualifiedAt: Date`.
2.  **Store Logic**: Update `handleQualified` in the store to populate the `qualifiedAt` timestamp on new entries.
3.  **Row Mapping**: Update `getBoardRows` (or equivalent selector) to tag rows with `justQualified: boolean` based on whether the player was just added in the current delta.
4.  **UI Component**:
    *   Create a `JustQualifiedBadge` component that renders `(just qualified)` with a fade-out animation.
    *   Inject this badge into the row header next to the player name.
    *   Apply a CSS slide-in-from-below animation to the row container when `justQualified` is true.
5.  **Styling**: Define CSS variables for animation durations and keyframes for the slide-in and fade effects.

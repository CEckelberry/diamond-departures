# Packet P7-02 — Accessibility Pass GREEN: Implementation Plan & Edits

## 1. Plan, Assumptions & Risks

### Assumptions
1.  **Framework**: The project uses Svelte (implied by `svelte-check` and `.svelte` file extensions).
2.  **Component Structure**:
    *   `Row.svelte`: Represents a selectable/activatable list item or media row.
    *   `PlayerDetail.svelte` (or similar): A modal/drawer component displaying player details, currently missing keyboard dismissal.
3.  **Styling**: Existing CSS classes are preserved to avoid visual regressions. We will add `role`, `tabindex`, and event handlers without altering layout.
4.  **Testing**: The test suite (`P7-02 tests`) expects:
    *   Keyboard activation via Enter/Space on rows.
    *   Escape key closing the player detail panel.
    *   No a11y warnings from `svelte-check` for these components.

### Risks & Mitigations
*   **Risk**: Adding `tabindex="0"` to non-interactive elements may cause unexpected focus order if not managed carefully.
    *   *Mitigation*: Ensure `Row` is naturally focusable or explicitly managed. Use `role="button"` or `role="row"` with appropriate activation handlers.
*   **Risk**: `Escape` key might close other modals in the stack if `PlayerDetail` is nested.
    *   *Mitigation*: Check if `PlayerDetail` is the topmost modal or use a portal/context to ensure it only closes itself. For this baseline, we assume it’s the primary focus trap target.
*   **Risk**: `svelte-check` may still warn about missing `aria-label` if the row content is purely visual.
    *   *Mitigation*: Add descriptive `aria-label` or `aria-labelledby` based on row content (e.g., track title, artist name).

### Implementation Strategy
1.  **Row.svelte**:
    *   Add `role="button"` and `tabindex="0"` to the root element.
    *   Handle `keydown` for Enter and Space to trigger the existing `click` handler.
    *   Add `aria-label` for screen readers.
2.  **PlayerDetail.svelte**:
    *   Add global `keydown` listener for `Escape` to close the panel.
    *   Ensure focus is trapped or returned appropriately (basic implementation: just close on Esc).
3.  **Verification**:
    *   Run `svelte-check` to confirm no a11y warnings.
    *   Run tests.

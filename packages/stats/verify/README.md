# stats verification dataset

Ground-truth rows curated from FanGraphs and Baseball Reference pages for representative player-seasons.

- Capture date: 2026-05-07 UTC
- Tolerance target: 0.5% relative error
- Sources are recorded per entry in `data.json` (`source.fangraphs`, `source.baseball_reference`).

This is a contract dataset for the verification harness, not a production feed.
